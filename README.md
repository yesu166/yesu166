## SELECTED BUILDS

### 🐝 HoneyChain
**Hive-to-consumer honey traceability + smart beekeeping platform**

A rural-first platform connecting beekeeper field workflows with batch traceability, laboratory verification, processing, custody, consumer verification and governed provenance.

**Core stack**

`Flutter` · `Python / FastAPI` · `React / TypeScript` · `PostgreSQL / Supabase` · `Hyperledger Fabric` · `Python ML`

**System path**

```text
Hive
  ↓
Harvest
  ↓
Batch
  ↓
Laboratory verification
  ↓
Processing / packaging
  ↓
Custody
  ↓
Honey Yatra QR
  ↓
Honey Passport
```

**Interesting engineering**

- Offline-first field capture and queued synchronization
- Server-side RBAC and resource/org scope checks
- SHA-256 commitments, Merkle proofs and hash-chained event records
- ECDSA P-256 device-reading attribution
- Hyperledger Fabric provenance anchoring
- Ask My Bee tool-using AI
- Hive-health screening and telemetry anomaly detection
- FPO market linkage and KVIC field operations

→ **[Open HoneyChain](https://github.com/yesu166/HoneyChain-Hexanexus)**

### 🧠 Gwen Agentic AI
**Cloud brain → real-device execution**

Gwen is an agentic AI system designed around a cloud-hosted Qwen brain while using the user's real Windows PC and Android devices as the execution layer.

```text
                         GWEN
                           │
                    AWS EC2 / Qwen
                           │
                       FastAPI
                           │
                        Planner
                           │
                       Tool Router
                           │
                       Tailscale
                  ┌────────┴────────┐
                  ▼                 ▼
             Windows PC         Android
             Hands + Eyes       Hands + Eyes
```

**Engineering direction**

- Structured tool calls instead of arbitrary shell execution
- Explicit action allowlists and risk levels
- Confirmation for destructive/high-impact operations
- Device connectivity through Tailscale
- Observe → act → verify loop
- Windows screenshot / app-control path
- Android interaction layer planned after the Windows path is stable

→ **[Open Gwen Agentic AI](https://github.com/yesu166/Gwen-Agentic-AI)**

## ENGINEERING RULES

```text
01  Don't call a mock a production feature.
02  Keep authorization on the server.
03  Prefer explicit state over silent fallbacks.
04  Make tools narrow, validated and observable.
05  Build the boring foundation before the flashy layer.
06  Measure what happened instead of trusting what an agent said happened.
```
