## SELECTED BUILDS

### [HoneyChain](https://github.com/yesu166/HoneyChain-Hexanexus)
**Hive-to-consumer traceability + smart beekeeping**

A large full-stack project connecting field capture, batch workflows, laboratory verification, processing, custody, QR-based consumer verification and provenance.

**Built with:** Flutter · FastAPI · React/TypeScript · PostgreSQL/Supabase · Hyperledger Fabric · Python ML

**Engineering highlights**
- Offline-first field workflows with queued synchronization.
- Server-side authentication, RBAC and resource/org scope checks.
- Provenance/evidence layers using hashing, Merkle proofs and Fabric anchoring.
- Honey Yatra QR + public Honey Passport flow.
- AI/ML integrations including health screening, anomaly detection and productivity-service integration.

**Status:** Active build. Some integrations remain prototype/service-dependent rather than production-complete.

---

### [Gwen Agentic AI](https://github.com/yesu166/Gwen-Agentic-AI)
**Cloud model brain → real-device execution**

An experimental agent architecture built around Qwen with a FastAPI backend and a secure path toward controlling real Windows and Android devices.

**Built around:** Qwen · llama.cpp · FastAPI · AWS EC2 · Tailscale · structured tool execution

**Engineering direction**
- Narrow tool/action interfaces rather than arbitrary shell access.
- Risk-aware actions and confirmation for high-impact operations.
- Device-side execution over private networking.
- Target loop: **observe → act → verify**.

**Status:** Experimental / active development.

---

### [Synthetic Threat Simulation Trainer](https://github.com/yesu166/Synthetic-Threat-Simulation-Trainer)
**Browser-based 3D simulation + training**

An interactive Three.js/WebGL environment for synthetic aerial-contact scenarios, explicit classification, reaction-time measurement, scoring, adaptive difficulty and after-action review.

**Built with:** JavaScript · Three.js · Vite · WebGL

**Status:** Experimental.
