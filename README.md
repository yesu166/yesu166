## About

I'm **Yesuraja (Yesu)** — a CSE student focused on applied AI and software engineering. I learn by building end-to-end projects: the interface, the API, the data flow, and the parts that break when the pieces meet.

I’m most interested in **agentic systems, full-stack applications, local-first desktop software, and interactive simulations**. I try to document what is working, what is experimental, and what still needs to be built.
