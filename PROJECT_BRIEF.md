# GitHub Profile | Project Brief

> **Proposed repository description:** GitHub profile and project index for Yesu, a CSE student building applied AI, full-stack applications, local-first desktop tools, and interactive simulations.

## Overview
This repository contains the profile README and visual assets shown on the GitHub account. Its purpose is to give visitors a clear, evidence-led overview of the developer's interests and selected projects.

## Audience and value
Recruiters, collaborators, fellow students, and open-source contributors should be able to understand what is being built, how to inspect it, and which parts are prototypes versus tested implementations without having to decode a wall of badges or inflated claims.

## Editorial direction
- Lead with identity, current study focus, and areas of engineering interest.
- Highlight a small number of representative projects with direct repository links.
- Describe each project's real purpose and maturity accurately.
- Prefer working demonstrations, tests, source links, and concise technical explanations over unsupported superlatives.
- Keep the Markdown readable when SVGs or external assets fail to load.

## Maintenance proposal
1. Re-check project links and demo links when a featured repository changes.
2. Update project status when meaningful functionality is implemented or tested.
3. Keep visual assets lightweight, legible, and accessible.
4. Remove stale metrics, broken badges, and claims that cannot be demonstrated.
5. Review the README on mobile and in GitHub's plain Markdown view.

## Collaboration
Because this is a personal profile repository, proposed changes should focus on corrections, accessibility, working links, and asset reliability. Use issues or pull requests for suggested improvements, while keeping personal details intentional.
